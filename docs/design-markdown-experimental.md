## 一、需求证据（回收自既有调研）

| 证据 | 来源 | 含义 |
|------|------|------|
| iA Writer 1★："No table of contents… can't use the app" | App Store | 结构化导航刚需 → **大纲已交付**（Cmd+Shift+O，天然服务 md） |
| MWeb 用户：中文字体无法应用到**预览和 PDF** | App Store 中文区 | 预览是 md 写作链路的一环，且**字体/排版**是中文用户敏感点 |
| 用户沉淀笔记在默认保存目录（实测 27 个 md 文件） | 本机实测 | 用户事实上在用 Jotpad 管理 Markdown 笔记库（跨文件搜索已覆盖） |
| ROADMAP v0.5 决策点 | ROADMAP | "若反馈强烈要求富文本/插图，应单独立项"——本立项**不含富文本/插图**，保持纯文本基因 |

**定位结论**：Jotpad 的 Markdown = **纯文本的阅读增强**（高亮 + 预览），不是富文本编辑器。文件永远是 `.md` 纯文本。

## 二、实验特性（Experimental Features）机制

### 动机

新特性"先实验、后转正"：
1. 降低风险：默认关闭，不影响存量用户
2. 加快迭代：不稳定能力可随时调整/回退，无需保证兼容
3. 收集反馈：愿意尝鲜的用户先体验，稳定后转正开放

### 设计

- **存储**：`settings.experimental: Record<string, boolean>`（通用 map，未来特性复用）
- **默认值**：空对象（所有实验特性默认关闭）
- **归一化**：`normalizeSettings` 合并默认值，逐键 `!!` 布尔化
- **设置 UI**：设置页新增「实验特性」分区，每项一个 Toggle + 风险说明
- **门控约定**：功能代码读取 `settings.experimental.<key>`；i18n 键名 `settings.exp.<key>` / `settings.exp.<key>Desc`
- **转正标准**（后续逐特性评估）：默认开启不影响启动性能；无未修 P0/P1 缺陷；连续两个版本无回归

### 首个实验特性 key

`markdown` —— v0.5 Markdown（语法高亮 + 预览面板）。

## 三、v0.5 首期范围（实验特性内）

| 功能 | 说明 | 状态 |
|------|------|------|
| **语法高亮** | `.md/.markdown/.mdx` 文件启用 CodeMirror markdown 语言支持（标题/列表/代码块/链接等着色） | 首期 |
| **预览面板** | `Cmd/Ctrl+/` 或「查看」菜单切换，编辑/预览左右分栏，渲染防抖 300ms，随内容实时刷新 | 首期 |
| 大纲跳转 | 已有（`parseOutline` 天然解析 md 标题） | ✅ 已交付 |
| 格式工具栏 | 插入粗体/标题/列表标记 | 暂缓（易与"纯记事本"人设冲突） |
| 富文本/图片/附件 | **不做**（ROADMAP 明确） | — |

### 技术选型

| 项 | 选型 | 理由 |
|----|------|------|
| 高亮 | `@codemirror/lang-markdown` | CodeMirror 官方语言包，与现有编辑器零缝集成；不带嵌套代码语言（避免依赖膨胀） |
| 预览渲染 | `marked` + **先转义后渲染** | 轻量（gz ~12KB）；先对源文本做 HTML 转义再交给 marked，输出标签全部为渲染器自产 → 零依赖防 XSS（源内 HTML 按字面显示） |
| 分栏 | `editor-wrap-host` 内 flex 行布局 | 复用现有容器，不动窗口结构 |

### 风险与对策

- 依赖增加 2 个前端包（lang-markdown + @lezer/markdown、marked），实测主包 +≈105KB gz（大于最初估计）；实验特性默认关闭，但包体随主包加载——若影响启动体感，后续改为 flag 开启时 dynamic import 按需加载
- 预览 XSS → 转义前置，源内 HTML 不执行
- 实验特性误开 → 设置页明确"实验特性，可能不稳定"文案
- 大文件预览性能 → 复用 BIG_FILE 阈值：>2MB（只读 tab）时预览仍渲染但不跟随输入（输入本就被只读阻断）

## 四、验收（首期）

1. 默认全新安装：无任何实验特性开启，无 markdown 高亮/预览入口行为
2. 开启实验特性 `markdown` 后：
   - 打开 `.md` 文件出现语法着色；关闭开关即时恢复纯文本
   - `Cmd/Ctrl+/` 切换分栏预览；编辑内容 300ms 内刷新
   - 非 md 文件 / 未保存 tab：预览菜单禁用
3. 设置页「实验特性」分区显示开关与说明
4. 回归：tsc / vitest / build 全绿；现有功能不受默认路径影响
